## 📦 Installation

MoIcons is built with **Motion for React**.

Install Motion using your preferred package manager.

### npm

```bash
npm install motion
```

### pnpm

```bash
pnpm add motion
```

### yarn

```bash
yarn add motion
```

### bun

```bash
bun add motion
```

After installing Motion, simply copy any icon component from MoIcons into your project.

No additional setup required.
